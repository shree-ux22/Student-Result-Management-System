# Student Result Management System

A beginner-friendly Python project designed to manage student information, subject marks, grades, percentages, and result reports.

## About the Project

The Student Result Management System is a console-based Python application that allows users to enter student details and marks for different subjects.

The program automatically calculates the total marks, percentage, grade, and pass/fail status. It also identifies the highest and lowest scoring subjects and saves the student's result as a text file.

## Features

- Student information management
- Subject-wise marks input
- Marks validation
- Automatic total marks calculation
- Percentage calculation
- Grade calculation
- Pass/Fail result
- Highest and lowest subject identification
- Automatic result report generation
- Text file report saving
- Multiple student entry support
- Date and time display
